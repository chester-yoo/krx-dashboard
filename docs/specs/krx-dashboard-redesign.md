## Problem Statement

현재 KRX 대시보드는 하나의 화면에서 상장사 전체를 "관리종목 위험도" 관점으로만 보여준다. 팀원(내부 공유 사용자)은 투자 후보 발굴이 목적인데, 단계(전체 / 거래정지 / 시가총액 미달 / 신규 기준 사전검토)마다 봐야 할 지표와 필터가 다르다. 그런데 현재는 모든 단계가 같은 필터와 컬럼을 공유한다. 재무정보(매출, 이익, 부채 등)는 종목을 클릭해야 상세 패널에서만 볼 수 있어서, 재무 기준으로 후보군을 걸러낼 수 없다. 또한 2027년 1월부터 시가총액 기준이 상향(코스피 500억, 코스닥 300억)될 예정인데, 이 변화의 영향을 받는 종목을 미리 추출하는 기능이 없다.

## Solution

좌측 네비게이션으로 4개 메뉴를 분리하고, 메뉴마다 고유한 컬럼과 필터를 제공한다.

1. 전체 상장사: 기본 스크리닝(시장, 업종, 시총 구간, 검색)
2. 거래정지: 거래정지 종목 목록 + 재무정보 컬럼
3. 시가총액 미달: 현행 기준(코스피 300억 / 코스닥 200억, 30거래일 연속 미달) 미달 종목 + 재무정보 컬럼 + 강화된 재무 필터
4. 신규 기준 사전검토(2027.1): 최근 30거래일 평균 시가총액이 신규 기준(코스피 500억 / 코스닥 300억) 미만인 종목을 모두 추출 + 재무정보 컬럼 + 강화된 재무 필터

2, 3, 4번 메뉴는 재무 요약(매출, 영업이익, 이익률, 순이익, 자산·부채·자본, 부채비율, 매출성장률, PBR, 자본잠식 여부)을 표 컬럼으로 직접 보여준다. 3, 4번은 이 재무 지표로 필터링할 수 있다. 팀원은 임계값을 직접 입력한다.

## User Stories

1. As a 투자팀원, I want 좌측 네비게이션에서 메뉴를 전환, so that 단계별로 필요한 목록만 집중해서 볼 수 있다
2. As a 투자팀원, I want 현재 메뉴가 네비게이션에서 강조 표시, so that 내가 어느 목록을 보고 있는지 헷갈리지 않는다
3. As a 투자팀원, I want 메뉴 전환 후에도 URL로 해당 메뉴를 바로 열 수 있음, so that 동료에게 특정 메뉴 링크를 공유할 수 있다
4. As a 투자팀원, I want 메뉴별로 필터 상태가 독립적으로 유지, so that 한 메뉴의 조건이 다른 메뉴 결과에 영향을 주지 않는다
5. As a 투자팀원, I want 전체 상장사 메뉴에서 시장, 업종, 시총 구간, 종목명/코드로 검색, so that 관심 종목군을 빠르게 좁힐 수 있다
6. As a 투자팀원, I want 전체 상장사 메뉴에서 종목 수 요약(전체, 코스피, 코스닥), so that 모집단 규모를 한눈에 파악한다
7. As a 투자팀원, I want 거래정지 메뉴에서 현재 거래정지 중인 종목만 확인, so that 정지 종목을 별도로 검토할 수 있다
8. As a 투자팀원, I want 거래정지 종목의 정지 일수와 정지 직전 시가총액 확인, so that 정지 기간과 정지 전 규모를 가늠할 수 있다
9. As a 투자팀원, I want 보유 데이터 기간(62거래일)보다 오래된 정지는 "62일 이상"으로 표시, so that 데이터 한계를 오해하지 않는다
10. As a 투자팀원, I want 거래정지 종목에서 재무정보 컬럼 확인, so that 정지 종목의 재무 상태를 한 표에서 비교한다
11. As a 투자팀원, I want 시가총액 미달 메뉴에서 현행 기준(코스피 300억, 코스닥 200억) 대비 부족 비율과 연속미달일수 확인, so that 지정 위험 정도를 판단한다
12. As a 투자팀원, I want 시가총액 미달 메뉴에서 연속미달 N일 이상 필터와 상태(주의, 임박, 대상) 필터, so that 위험 단계별로 추릴 수 있다
13. As a 투자팀원, I want 시가총액 미달 메뉴의 표에 재무정보 컬럼, so that 클릭하지 않고도 종목을 비교한다
14. As a 투자팀원, I want 시가총액 미달 메뉴에서 영업이익 흑자/적자, 영업이익률 하한으로 필터, so that 수익성 있는 미달 종목만 본다
15. As a 투자팀원, I want 시가총액 미달 메뉴에서 순이익 흑자/적자로 필터, so that 이익 창출 여부로 후보를 거른다
16. As a 투자팀원, I want 시가총액 미달 메뉴에서 매출 성장률 하한으로 필터, so that 성장하는 종목만 본다
17. As a 투자팀원, I want 시가총액 미달 메뉴에서 부채비율 상한으로 필터, so that 재무 안정적인 종목만 본다
18. As a 투자팀원, I want 시가총액 미달 메뉴에서 PBR 상한, PER 상한으로 필터, so that 저평가 종목을 찾는다
19. As a 투자팀원, I want 시가총액 미달 메뉴에서 자본잠식 종목 제외 옵션, so that 재무 부실 종목을 걸러낸다
20. As a 투자팀원, I want 신규 기준 사전검토 메뉴에서 코스피 500억, 코스닥 300억 기준 미만 종목을 모두 확인, so that 2027.1 기준 상향 영향 종목을 미리 파악한다

## Implementation Decisions

- **네비게이션 구조**: 좌측 고정 사이드바에 4개 메뉴(전체 상장사, 거래정지, 시가총액 미달, 신규 기준 사전검토). 단일 정적 페이지 안에서 뷰를 전환한다. 메뉴는 URL 해시로 식별해 링크 공유가 가능하다.
- **메뉴별 독립 상태**: 각 뷰가 자체 필터와 정렬 상태를 가진다. 공통 요소(표, 상세 패널, 재무 컬럼 렌더링)는 공유 컴포넌트로 만들어 중복을 피한다.
- **메뉴 명칭**: 기존 "관리종목"은 혼동을 피하려고 "시가총액 미달"로 변경한다. KRX가 실제 지정한 관리종목 목록은 수집하지 않으며, "지정 대상"은 대시보드 자체 계산값임을 화면에 명시한다.
- **전체 상장사**: 기존 history 데이터의 최신 일자 기준 전 종목. 필터는 시장, 업종, 시총 최소/최대, 검색.
- **거래정지**: 최신 일자 거래정지 플래그가 참인 종목. 정지 일수는 보유 이력에서 최신일부터 거꾸로 연속 정지일수를 센다. 이력 시작일(62거래일 기준)까지 연속되면 "N일 이상(데이터 시작일 도달)"로 표기한다. 정지 직전 시총은 정지 직전 거래일의 시가총액이다.
- **시가총액 미달**: 현행 판정 로직 유지(코스피 300억, 코스닥 200억, 30거래일 연속 미달, 상태 4단계). 신규로 재무 컬럼과 재무 필터를 추가한다. 기존 "관리종목 지정 기준일수" 입력은 "연속미달 N일 이상" 필터로 이름을 바꾼다.
- **신규 기준 사전검토 판정**: 종목별 최근 30거래일 단순평균 시가총액(억원)을 구해 시장별 신규 기준(코스피 500억, 코스닥 300억) 미만이면 포함한다. 연속미달일수는 쓰지 않는다. 표시 지표는 30일 평균 시총, 신규 기준 대비 %, 현행 기준 대비 %, "현행 통과 / 신규 미달" 구분이다. 현행 기준 통과 여부는 최신 시총 또는 30일 평균 중 무엇으로 판단할지 구현 시 하나로 정해 화면에 명시한다. 거래일이 30일 미만인 종목은 보유 일수 평균을 쓰고 표기한다(신규 상장 등).
- **재무 컬럼(2, 3, 4번 메뉴)**: 최근 사업연도 기준 매출액, 영업이익, 영업이익률, 당기순이익, 순이익률, 자산총계, 부채총계, 자본총계, 부채비율, 매출성장률(전년 대비), PBR, 자본잠식 여부. 재무 기준은 기존 수집 규칙(연결 우선, 없으면 별도)을 따르고 컬럼에 연결/별도를 표기한다.
- **계산식과 가정(화면에 표기)**:
  - 영업이익률 = 영업이익 ÷ 매출액, 순이익률 = 당기순이익 ÷ 매출액, 부채비율 = 부채총계 ÷ 자본총계
  - 매출성장률 = (최근 사업연도 매출 ÷ 직전 사업연도 매출) − 1
  - PBR = 시가총액 ÷ 자본총계. 시가총액은 3번 메뉴에서는 최신일 시총, 4번 메뉴에서는 30일 평균 시총을 쓴다. 메뉴에 따라 분자가 다르므로 화면에 분자를 명시한다.
  - PER = 시가총액 ÷ 당기순이익. 순이익이 0 이하이면 "해당 없음(N/M)"으로 표시한다.
  - 시총과 재무 데이터의 시점이 다르므로(시총은 최근 일자, 재무는 최근 사업연도 말) 화면에 시점 차이를 안내한다.
- **재무 필터(3, 4번 메뉴)**: 영업이익 흑자/적자 선택(최근 연도, 3개년 연속 중 선택), 영업이익률 하한, 순이익 흑자/적자 선택, 매출성장률 하한, 부채비율 상한, PBR 상한, PER 상한, 자본잠식 제외(부분/완전 구분). 모든 임계값은 사용자가 직접 입력하며 기본값은 비워 둔다(임의 기본값을 정하지 않는다).
- **데이터 없음 처리**: 매출 등 항목이 비어 있으면 "데이터 없음"으로 표시하고 0으로 간주하지 않는다. 재무 필터 사용 시 "데이터 없음 종목 포함" 체크박스로 통제한다. 재무 데이터 보유율은 약 98%(2,543/2,595 종목)이고 매출 항목은 일부 종목에서 비어 있다.
- **자본잠식 판정에는 신규 데이터 수집이 필요**: 현재 재무 데이터에는 자본금이 없다. 부분잠식(자본총계 < 자본금) 판정을 위해 DART 주요계정 또는 재무제표에서 자본금을 추가 수집한다. 수집이 완료되기 전에는 완전잠식(자본총계 < 0)만 판정한다. 자본금 수집 이후 부분잠식을 활성화한다. 주요계정 응답에 자본금이 포함되는지는 구현 단계에서 확인한다.
- **규제 수치 설정화**: 현행 기준(300억/200억, 30일), 신규 기준(500억/300억), 평균 기간(30거래일), 신규 기준 시행일(2027-01)을 한 곳의 상수 블록으로 분리한다. 화면 문구는 이 상수에서 생성한다.
- **데이터 로딩 성능**: 현재 일별 이력 파일이 약 30MB라 메뉴가 늘면 초기 로딩이 병목이다. 목록 화면에 필요한 요약값(최신 시총, 30일 평균, 연속미달일수, 거래정지 정보)은 수집 단계(일일 배치)에서 사전 계산한 경량 요약 파일로 제공하고, 일별 이력은 상세 패널(차트) 진입 시에만 불러오는 방식으로 분리한다. 요약 파일 생성은 기존 일일 수집 워크플로에 추가한다.
- **재무 컬럼과 필터용 사전 계산**: 재무 파생 지표(이익률, 성장률, 부채비율)는 화면에서 계산해도 충분한 규모이나, PBR/PER은 메뉴별 시총 기준이 다르므로 화면에서 계산한다.
- **보안/공개 범위**: 저장소와 Pages URL은 공개(public)다. 현재 데이터는 KRX 시세와 DART 공시 등 공개 정보뿐이며, 이번 범위에서도 내부 관심종목, 메모, 담당자, 딜 정보 등 비공개 정보는 저장하지 않는다. 그런 기능이 필요해지면 비공개 호스팅으로 옮기고 사내 보안 확인을 거친다.
- **상세 패널**: 기존 시총 추이 차트, 연도별 재무, 주요사항보고 패널을 유지한다. 차트 기준선은 현행 기준과 신규 기준을 모두 표시한다(신규 기준선은 점선 등으로 구분).

## Out of Scope

- KRX가 실제 지정한 관리종목, 투자주의환기종목, 정리매매 종목의 수집(자체 계산 "시가총액 미달"만 다룬다)
- 거래정지 사유(감사의견 등) 수집
- 규칙 기반 자동 점수화(스코어링)와 프리셋 스크린 저장
- 검토대상 수동 지정, 메모, 담당자 등 팀 공유 상태와 사용자별 저장(별도 서버/비공개 호스팅 필요)
- 최대주주 지분율, 최대주주 변경, 유상증자/CB 이벤트 필터(공시 패널 표시는 유지, 필터화는 후속 과제)
- EV/EBITDA, 순현금, 차입금, 배당 지표(추가 DART 수집이 필요한 항목)
- 법무, 세무, 규제 해석(기준 금액과 시행일의 최종 확인은 사내 법무팀 및 KRX/금융당국 공식 자료 확인 필요)

## Further Notes

- **규제 수치 검증 필요**: "2027.1부터 코스피 500억, 코스닥 300억"은 기존 화면 문구에서 가져온 값이며 이번 작업에서 공식 출처로 검증하지 않았다. 시행일, 금액, 연속일수는 KRX 또는 금융위원회 공식 발표 및 사내 법무팀 확인이 필요하다. 설정값으로 분리하므로 변경은 한 곳에서 한다.
- **4번 메뉴의 성격**: 신규 기준 사전검토는 실제 지정 대상 판정이 아니라 "30일 평균 시총이 신규 기준 미만"인 종목의 단순 추출이다. 실제 관리종목 지정 요건(연속일수 등)과는 다르다는 점을 화면에 안내한다.
- **데이터 한계**: 이력은 2026-07-01부터 누적된 62거래일이다. 거래정지 일수와 30일 평균 모두 이 범위 안에서만 계산된다.
- **재무 시점**: 재무는 사업보고서 기준(최근 2025년) 연 1회 갱신 데이터라, 최신 분기 실적을 반영하지 않는다. 투자 판단 시 최신 분기/반기 보고서 확인이 필요하다.
- **PER**: 이번 논의에서 필터 표에 제안되었고 PBR, 매출성장률, 자본잠식과 함께 구현 대상으로 포함했다. 불필요하면 제외할 수 있다.
- **CSV 내보내기**: 사용자가 요청 여부를 명확히 답하지 않아 선택 사항으로 두었다.
- **배포 시 주의**: 데이터 봇이 매일 커밋하므로 작업 브랜치는 push 전에 최신 main과 rebase 해야 한다. 공유 URL이 배포 즉시 바뀌므로 작업 브랜치에서 검증 후 반영한다.
- 수치(재무, 시총)는 KRX Open API와 OpenDART 출처이며, 화면에는 출처와 기준일을 표기한다.
